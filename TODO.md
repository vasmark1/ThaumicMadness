## 💍 Раздел 2: Миграция и интеграция с [Baubles Expanded](https://github.com/GTNewHorizons/Baubles-Expanded) (GTNH Team)

- [x] **Подключение зависимости в `dependencies.gradle`**:
  - `devOnlyNonPublishable("com.github.GTNewHorizons:Baubles-Expanded:2.1.9:dev")` подключен через GTNH Nexus.
- [x] **Архитектура поддержки расширенных слотов (`baubles.api.expanded`)**:
  - Поддержка до 20 слотов инвентаря и стандартных типов `BaubleExpandedSlots`:
    - `amulet`, `ring`, `belt`, `head`, `body`, `charm`, `cape`, `shield`, `quiver`, `gauntlet`, `earring`, `wings`, `universal`.
  - Реализация базового класса `ItemBaubleBase` с интерфейсом `baubles.api.expanded.IBaubleExpanded` и поддержкой `String[] getBaubleTypes(ItemStack itemstack)`.
- [x] **Двунаправленный адаптер совместимости (Dual-Compatibility Wrapper)**:
  - Изолированная реализация: при наличии `Baubles-Expanded` используется `IBaubleExpanded`, при наличии ванильного `Baubles 1.0.1.10` используется `baubles.api.IBauble` (`BaubleType.AMULET / RING / BELT`).
  - Класс `BaublesCompat` с безопасными хелперами проверки экипировки без сбоев `NoClassDefFoundError`.
- [x] **Назначение слотов для предметов Thaumic Madness**:
  - [x] **Тауматургический Атлас (Thaumaturgical Atlas)**: сохранён как ручной/инвентарный фолиант (не требует и не занимает слоты Baubles).
  - [x] **Кровавые амулеты и кольца (Blood Magic Compat)**: `ItemBloodRing` (слоты `ring`, `charm`, `amulet`), `ItemBloodAmulet` (слоты `amulet`, `body`, `charm`).
  - [x] **Обереги рассудка и защиты от искажения (Warp Ward Trinkets)**: `ItemSanityCharm` (слоты `charm`, `head`, `earring`, `amulet`).
- [x] **Интеграция с Soulbound & сохранениями**:
  - Поддержка тегов и зачарований сохранения экипированных предметов при смерти.

## 🏗️ Раздел 3: Компактные механизмы 1х1 (Сжатие мультиблоков)

Создание линейки высокотехнологичных/магических компактных моноблоков 1x1, заменяющих громоздкие многоблочные конструкции с сохранением полного функционала и баланса.

### 3.1. 🔮 Компактная матрица наполнения (Compact Infusion Matrix 1x1)
* **Заменяет**: Алтарь наполнения 3x3x3 + 8-16 пьедесталов + матрицу + сотни свечей/голов/стабилизаторов.
* **Функционал**:
  * Внутренний виртуальный инвентарь: 1 центральный слот + до 16 слотов для компонентов рецепта.
  * Виртуальный буфер стабильности: слоты для установки стабилизаторов (свечи, черепа, кристаллы) прямо в интерфейсе блока, либо постоянная 100% стабильность на высшем тире.
  * Автоматическое выкачивание эссенции: прямое подключение к банкам, трубам или МЭ Essentia Provider (ThE) без риска разбрызгивания.
  * GUI с анимацией процесса наполнения, таймером и отображением необходимой эссенции.

### 3.2. 🔥 Компактная адская печь (Compact Infernal Furnace 1x1)
* **Заменяет**: Мультиблок адской печи 3x3x3 (обсидиан, адские кирпичи, лава, решетка).
* **Функционал**:
  * Моментальная/ускоренная плавка руд и предметов.
  * Сохранение шанса выпадения самородков, редких ресурсов и опыта Thaumcraft.
  * Внутреннее улавливание порчи (Flux) без загрязнения чанка.
  * Поддержка ускорения аспектом Ignis / маной Botania Exoflame.

### 3.3. 🩸 Компактный алтарь крови (Compact Blood Altar 1x1 — Теры 1–6)
* **Заменяет**: Пирамиду алтаря крови Blood Magic (от 1x1 до 19x19x9 блоков с рунами).
* **Функционал**:
  * Переключение тира (Tier I – VI) через внутренний апгрейд ядра или виртуальные руны.
  * Внутренний контейнер под руны: Руны скорости, Жертвоприношения, Самопожертвования, Ёмкости, Дислокации, Ускорения и Сферы.
  * Прямая синхронизация с Soul Network владельца через Кровавый шар.
  * Входы/выходы для авто-подачи предметов (трубы, воронки, МЭ интерфейсы).

### 3.4. 🧪 Компактная алхимическая перегонка (Compact Alchemical Distillery 1x1)
* **Заменяет**: Алхимическую печь + перегонные кубы (алембики) + очистители эссенции.
* **Функционал**:
  * Мгновенное растворение предметов в эссенцию.
  * Внутренний буфер на 64+ различных аспектов без необходимости ставить столб из 10+ алембиков.
  * Прямой вывод эссенции по трубам или в МЭ систему.
  * Встроенная 100% фильтрация выбросов (ноль загрязнения местности).

### 3.5. 🌌 Компактный синтезатор узлов ауры (Compact Node Synthesizer 1x1)
* **Заменяет**: Манипуляторы узлами Technomancy / камеры выращивания Nodal Mechanics / преобразователи узлов.
* **Функционал**:
  * Загрузка узла в банке (Node in a Jar).
  * Кормление эссенцией или RF энергией для увеличения емкости и изменения типа узла (например, превращение Tainted -> Pure).

### 3.6. 🌸 Компактные механизмы Botania (Compact Botania 1x1 Multiblocks)
* **3.6.1. Компактное ядро агломерации Террастали (Compact Terrestrial Agglomeration Core 1x1)**:
  * **Заменяет**: Платформу агломерации террастали (Плита агломерации + 4 блока жизнекамня + 4 блока лазурита + бассейны маны с искрами).
  * **Функционал**:
    * Внутренний приём и буфер маны (Mana Receiver / Spark Slot).
    * Автоматический синтез Террастали (Terrasteel) без выбрасывания предметов в мир и риска деспавна.
    * Полная совместимость с трубами, воронками и МЭ-интерфейсами.
* **3.6.2. Компактный портал Альфхейма (Compact Elven Gateway 1x1)**:
  * **Заменяет**: Мультиблок Врат в Альфхейм (8 блоков жизнедерева + 2 пилона Natura/Gaia + 2 бассейна маны + ядро врат).
  * **Функционал**:
    * Мгновенный обмен ресурсов с эльфами (Жизнедерево -> Древесина мечтаний, Алмазы -> Камень дракона, Жемчуг -> Пыль пикси / Эльфийский кварц / Лексика Botania).
    * Внутренний буфер маны без необходимости удерживать открытый портал с нагрузкой на рендер.
* **3.6.3. Компактная руническая матрица (Compact Runic Altar 1x1)**:
  * **Заменяет**: Алтарь рун Botania с бросанием компонентов в мир и кликом посохом леса.
  * **Функционал**:
    * Автоматический крафт всех 16 типов рун (Стихии, Сезоны, Грехи).
    * Встроенный слот под Жизнекамень и автоматическое поглощение маны.
* **3.6.4. Компактный аптекарь цветов (Compact Petal Apothecary 1x1)**:
  * **Заменяет**: Аптекарь лепестков с ручным заливом воды и бросанием семян.
  * **Функционал**:
    * Бесконечный внутренний резервуар воды.
    * Пакетный крафт функциональных и генерирующих цветов по шаблонам рецептов.
