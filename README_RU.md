# Thaumic Madness

[ English ](README.md) | [ Русский ](README_RU.md)

---

**Thaumic Madness** — это комплексный аддон для Thaumcraft 4 (Minecraft 1.7.10), созданный для модернизации, расширения и улучшения тауматургического геймплея, а также интеграции Thaumcraft с Blood Magic и другими популярными магическими модификациями.

---

## 🔮 Ключевые особенности

### 📖 Всевидящий Таумономикон и Тауматургический Атлас (Thaumaturgical Atlas)
* **Единый фолиант**: Объединяет Таумономикон, Таумометр, Чувствительный к вис амулет и Очки откровения в матрице наполнения.
* **Двойной интерфейс**:
  * **ПКМ**: Стандартная книга исследований Таумономикона.
  * **Shift + ПКМ**: Открывает мистический **Атлас узлов ауры**.
* **Пассивное зрение откровения**: Предоставляет эффект Очков откровения и просмотр аспектов узлов ауры прямо из инвентаря игрока без необходимости надевать их в слот шлема (реализовано на нативных SpongePowered Mixins).

### 🧭 Трекер узлов ауры (Aura Node Tracker) и Интерактивные объекты JourneyMap
* **База данных узлов ауры**: Сканирует и сохраняет все исследованные таумометром узлы во всех измерениях.
* **Сортировка и поиск в реальном времени**: Фильтрация по аспектам, типу узла (Чистый, Зловещий, Голодный, Заражённый, Нестабильный) и яркости.
* **Внутриигровой HUD-компас**: Отображение расстояния, стрелки направления и состава аспектов прямо на экране для быстрого поиска выбранного узла.
* **Интерактивная интеграция с JourneyMap**:
  * Отображение найденных узлов на полноэкранной и мини-карте JourneyMap в виде динамических светящихся магических сфер.
  * Цвет сферы точно отражает тип узла (Чистый — циан, Голодный — алый, Заражённый — порченый маджента, Зловещий — индиго, Нестабильный — золотой, Обычный — по доминирующему первичному аспекту).
  * Информативные карточки-подсказки при наведении курсора с координатами, аспектами и суммарным запасом Vis.
  * Интерактивный клик по сфере для открытия подробного окна узла с кнопками GPS-трекинга и перехода в Атлас.

### 🩸 Интеграция с Blood Magic и Blood Arsenal
* **Отдельная вкладка исследований**: Полноценная ветка исследований в Таумономиконе.
* **Кровавые стержни и наконечники**: Создаются на Алтаре крови и в Матрице наполнения, дают скидки на вис и регенерацию за счёт LP (Life Essence).
* **Набалдашник: Кровавое жертвоприношение (Blood Sacrifice)**: Использует LP для рунических снарядов или жертвенной подзарядки крови.
* **Зарядка жезлов на Алтаре крови**: Безопасная передача жизненной эссенции для восполнения запасов вис в жезлах.

### 🧠 Интерфейс искажения и рассудка (Warp & Sanity HUD)
* **Индикатор искажения в инвентаре**: Наглядная шкала постоянного, призрачного и временного искажения прямо в окне инвентаря игрока при наличии Измерителя искажения (Sanity Checker).
* **Интеграция с NEI**: Просмотр искажения и сервисные кнопки управления через NotEnoughItems.

### 🖋️ HD-шрифты и визуальные улучшения
* **Чёткий HD-шрифт**: Сглаженное отображение текста на страницах Таумономикона.
* **Масштабирование аспектов**: Опция 2x увеличения иконок аспектов для удобного чтения всплывающих подсказок.

### 🌐 Встроенные локализации аддонов
* Автоматический встроенный ресурспак с полным переводом на русский и английский языки для ключевых аддонов Thaumcraft: **Gadomancy**, **WarpTheory**, **WitchingGadgets**, **ThaumicBases**, **ThaumicExploration**, **AdvThaum**, **TCNodeTracker**, **TCInventoryScan** и др.

### ⚙️ Модульная внутриигровая конфигурация
* Доступ к настройкам через `Моды` -> `Thaumic Madness` -> `Настройки` в главном меню или во время игры.
* Включение и отключение HUD, пассивного зрения, HD-шрифтов и модулей контента на лету без перезапуска игры.

## 🛠️ Сборка из исходников

### Требования
* Java Development Kit (JDK) 8 или новее.

### Команда сборки
```bash
./gradlew spotlessApply build
```
Скомпилированный `.jar` файл мода будет находиться в папке `build/libs/`.

### Запуск клиента для разработки
```bash
./gradlew runClient
```
